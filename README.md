🎯 使用方式
方法一：選擇常用句
選擇翻譯模式
🇨🇳 中英模式
🇯🇵 日語模式
🇰🇷 韓語模式
點選下拉選單
選擇需要的句子
系統自動顯示翻譯結果
方法二：手動輸入
選擇翻譯模式
在輸入框輸入文字

例如：

請問車站在哪裡
按【翻譯】
顯示翻譯結果
方法三：語音輸入
點選【🎤 語音輸入】
對著手機說話

例如：

我要去機場
系統自動辨識
按【翻譯】

可自行建立常用翻譯。
